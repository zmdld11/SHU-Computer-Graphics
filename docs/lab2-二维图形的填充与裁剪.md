# 实验二：二维图形的填充与裁剪

> 前置：基于实验一的引擎框架继续扩展。

## 必做内容

1. **多边形扫描转换**：扫描线算法（支持任意多边形）
2. **连通区域填充**：扫描线填充算法
3. **直线段裁剪**：Cohen-Sutherland 或 中点分割裁剪算法（二选一）

## 验收要点

- [ ] 鼠标点选/键盘输入多边形顶点，扫描线填充正确（含凹多边形）
- [ ] 顶点穿过扫描线时交点计数正确（奇偶规则）
- [ ] 种子填充：鼠标点种子，内点填充不泄漏边界
- [ ] 裁剪：完全可见 / 完全不可见 / 部分可见三类线段均正确
- [ ] 全程交互式输入

## 挑战问题

- [ ] 裁剪窗口为**任意凸多边形**的裁剪（可研究 Cyrus-Beck 算法）
