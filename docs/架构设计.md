## 3. 依赖规则（红线）

| 规则 | 内容 |
|---|---|
| 允许方向 | main → 各层；ui → raster/geom/curves/core；raster/geom/curves → core；core 不依赖任何本仓库模块；tests 可依赖全部层（仅测试用，不参与运行时） |
| 禁止反向 | 算法层（raster/geom/curves）**不得** include `src/ui` 下任何头文件 |
| OpenGL 边界 | 仅 `Canvas` 使用 OpenGL（自写加载器 GLLoader，LoaderFn 由 Window 注入），其余代码与 GL 无关 |
| GLFW 边界 | 仅 `Window` 使用 GLFW；算法层经回调收到的是纯 int/float 事件 |
| 画点入口 | 一切绘制最终经 `FrameBuffer::putPixel`（课程红线：算法手写；自绘任务栏文字同样只走 putPixel——系统字体由 GDI 预先栅格化成点阵再逐像素写入，非 Windows 回退 5×7 点阵） |
| 渲染分层 | `PaintController` 分"提交层（图形列表重绘，变化时才重算）+ 预览层（每帧叠加）"；种子填充等算法不每帧重放；**常驻裁剪是显示层掩码拷贝**（窗口内照抄提交层、窗口外回黑），不改提交层 |
| 期末项目 | Animation 只调 PaintController 公开接口驱动图形，不改引擎内部 |

## 4. 未来模块接入说明

- ~~实验三 Transform~~ **已接入（lab3）**：Mat3 全套实现；变换模式（键 7）鼠标单选 / Shift 多选，拖拽与方向键平移，`+/-` 等比缩放、`R/T` 旋转。**已定设计决策**：线段/多边形直接变换顶点；圆/圆弧走"变换圆心 + 等比缩放半径 + 旋转角度"的参数化处理（非等比缩放会把圆变椭圆，超出参数表达能力，不支持）；图形参数为整数像素坐标，矩阵结果四舍五入回存（连续精细变换会有 ±1px 舍入，拖拽平移用整数增量规避）。挑战题：`J` 对接拼接——吸附两图形轮廓最近点为对接点，对 B 施加 M = T(A−B)·R(B,Δθ)（Δθ 为两切向角差，±90° 内取最短）。
- ~~实验四 Bezier~~ **已接入（lab4，#46/#47）**：de Casteljau（`sampleBezier`/`deCasteljauAt`）+ 挑战题 clamped B 样条（`sampleBSpline`，Cox-de Boor）。曲线模式（键 8）：连点控制点、右键提交、**拖拽控制点实时改形**、`B` 键切样条；曲线以 128 段采样折线渲染。**已定设计决策**：控制点表用 `FPoint` 浮点存储，变换直接作用控制点、保留浮点精度（与多边形取整回存不同）；曲线作为参数图形完整接入选中/框选/重心/对接（重心=控制点平均，与多边形同口径）。
- **实验五（选做）LightingRenderer**：独立三维支线，仅依赖 FrameBuffer 软渲染（Lambert/Phong 逐像素），不与 2D 交互耦合；模型文件放 `assets/`。
- **期末项目 Animation**：时间轴/关键帧驱动 Shape 列表做变换，复用实验三矩阵与实验一/二图元；**运动路径可直接用 curves 模块采样**（Bezier/B 样条即动画轨迹），只走公开接口。

## 5. 已知架构债（后续顺手清理）

1. `Window.hpp` 为复用 `LoaderFn` 而 include 了 `Canvas.hpp`——`LoaderFn` 已移至 `core/GLLoader.hpp`，把 `Window.hpp` 的 include 改为 GLLoader.hpp 即可彻底解开（顺手清理项）。
2. `PaintController` 是交互中枢，实验三/四接入后职责会继续膨胀——届时视情况拆出 `ShapeDocument`（图形列表+选中）与工具类。
3. ~~`Shape` 用参数化字段存圆/弧，实验三变换时需按类型分支处理~~ 已解决：applyToShape 按类型分支（lab3），决策记录见上文与 issue #35。
4. 种子填充以画板像素为操作对象（教材做法）：若后续引入反走样（CH4）使边界出现过渡色，需改为"按边界色判据"的填充。

## 附：交互状态机（实验一/二/三/四）

| 模式（键） | 交互 |
|---|---|
| 直线/圆（1/2） | 左键拖拽：按下定起点（圆心），移动预览，松开提交 |
| 圆弧（3） | 两阶段：拖拽定圆心/半径/起点角 → 移动调终止角 → 左键确认 |
| 多边形（4） | 左键连点加顶点（橡皮筋预览）→ 右键闭合（≥3 点）；`F` 切填充/仅轮廓（连点中=本次；其他=最后一个已闭合多边形） |
| 种子填充（5） | 左键点击封闭区域内一点即填充；`X` 循环填充色 |
| 裁剪（6） | 左键拖拽画线（算法演示：灰虚线原段+绿实线裁剪段）；`K`+拖拽设矩形窗口；`P`+连点+右键闭合设凸多边形窗口；`M` 切换 C-S/中点分割。**显式定义窗口后常驻裁剪开启**：窗口青色虚线常驻所有模式，只显示窗口内内容；`V`/任务栏开关 |
| 变换（7） | 左键选中（Shift 加选/移除）；**空白处拖拽框选**（橡皮筋矩形，相交全选，Shift 叠加；微点=清除）；拖拽/方向键平移；**画板式选择**：橙色高亮+虚线外接矩形+控制柄（单选线段=拖两端点改形；角柄缩放/边柄单轴缩放；含圆/弧=4 角柄等比）；`Del` 删除选中；`+/-` 缩放；`R/T` 旋转；`G` 参考点 重心↔指定；`J` 对接拼接（点 A 轮廓 → 点 B 轮廓） |
| 曲线（8） | 左键连点加控制点（以光标作临时末控制点实时预览曲线）→ 右键提交（≥2 点）；`B` 切新曲线类型 Bezier⇄B 样条；**点住已提交曲线的控制点拖拽**实时改形（控制多边形灰虚线+青色手柄，拖拽点橙色高亮） |
| 任务栏（任意模式） | 顶部两行自绘按钮（系统字体中文标签）= 全部键盘操作的鼠标等价物；与键盘共用 `handleAction` 入口；点中按钮的事件不落入画布 |
