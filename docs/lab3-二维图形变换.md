# 实验三：二维图形变换

> 前置：基于实验一、二的引擎框架；图形对象需可选中、可管理。

## 必做内容

平移、放缩、旋转三种几何变换。

## 验收要点

- [ ] 绘图区存在**多个图形**，鼠标可**选中一个或多个**后执行变换
- [ ] 变换默认参考点为**图形重心**
- [ ] 支持以**任意点**为参考点执行三种变换（T·R·T⁻¹ 三步复合）
- [ ] 齐次坐标 / 矩阵实现（不是逐点 if-else 拼坐标）

## 挑战问题

- [ ] 在两个图形轮廓上指定**对接点**，通过几何变换将两图形在对接点处**拼接**

规定时间内验收；源码 + 可运行文件打包上传超星。
