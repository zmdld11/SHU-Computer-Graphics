# 实验二：二维图形的填充与裁剪

> 来源：《计算机图形学》实验要求 PDF（与实验一至四需在**同一个程序框架**中实现）。
> 状态：**已完成**（分支 `lab2`，tag `lab2`）。四个任务统一验收（老师确认）。

## 必做内容

- [x] 二维扫描转换多边形的**扫描线算法**（任意多边形绘制）
  - 新边表 NET + 活性边表 AET；非水平边按半开区间 `[ymin, ymax)` 求交，自动满足顶点计数规则
- [x] 二维连通区域填充的**扫描线填充算法**
  - 扫描线种子填充：填充像素段，上下相邻行新段取代表像素入栈（非逐像素入栈）
- [x] 二维直线段裁剪的 **Cohen-Sutherland** 或**中点分割**裁剪算法
  - 两种都实现：C-S 编码裁剪 + 中点分割（纯整数二分），可按键切换并用断言互验

## 要求

- [x] 通过键盘或鼠标交互输入算法所需数据

## 挑战问题

- [x] 裁剪窗口为任意**凸多边形**的裁剪（Cyrus-Beck 参数化裁剪；`P` 键连点定义窗口）

## 后续改进（验收后 extension，不改变上方验收内容）

- **常驻裁剪**（#43，UX 改进——实验说明未要求）：裁剪"画框"与"算法定义"解耦。显式定义窗口
  （`K` 拖拽 / `P` 凸多边形）后窗口常驻所有模式，任意模式画的图形都只显示窗口内部分（显示层
  缓存 + 行级拷贝，不改提交层）；`V` 键/任务栏随时开关；裁剪模式内的 C-S/中点/CB 算法演示线保持原样。
- **种子填充绑定所属闭合图形**（#57，交互修复，不改变算法）：在圆/多边形内部点击种子填充时，
  记录种子所属图形的稳定 id；变换该图形时种子用同一矩阵移动/缩放，并做内部钳制。`scanlineSeedFill`
  仍是原来的扫描线种子填充；圆外/任意连通区域的自由种子填充行为不变。这样解决了"圆缩小后种子
  落到圆外、填充翻到背景"的问题，也避免整屏 flood fill 造成的拖拽卡顿。
