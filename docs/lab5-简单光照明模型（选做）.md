# 实验五（选做）：简单光照明模型的实现

> 加分项；做完实验一~四且学有余力再做。

## 必做内容

三维模型的 **Lambert 模型**和 **Phong 模型**渲染。

## 验收要点

- [ ] **通过文件导入模型数据**（如 OBJ 格式：v 顶点行 / f 面行）
- [ ] Lambert 漫反射渲染正确（亮度随表面朝向变化）
- [ ] Phong 模型渲染正确（环境光 + 漫反射 + 镜面高光）
- [ ] 可旋转/缩放观察模型（交互）

## 挑战问题

- [ ] 读入模型几何数据后，**自己编写算法计算光照所需数据**（顶点法向：面法向按面积加权平均到顶点）

## 提交

规定时间内验收；源码 + 可运行文件打包上传超星。

## 备注

- 这是全书 CH12 的直接实践，对期末书面考试的光照计算题也有帮助
- 渲染仍可软件实现（逐像素/逐顶点计算），不强制使用可编程管线
