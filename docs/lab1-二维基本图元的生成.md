# 实验一：二维基本图元的生成

> 来源：《计算机图形学》实验要求。实验一~四必须在**同一个程序框架**中实现，人机交互驱动。

## 必做内容

1. **直线段生成**：中点算法 或 Bresenham 算法
2. **圆弧生成**：中点算法
3. **线型、线宽属性**控制

## 验收要点

- [ ] 键盘或鼠标交互输入算法所需数据（端点、圆心半径等）
- [ ] 直线绘制支持**任意斜率**（水平/垂直/|m|>1/m<1/负斜率都要对）
- [ ] 线型：至少实现实线 + 虚线（点线可选）
- [ ] 线宽：至少两种宽度
- [ ] **算法手写**，不调用图形库现成画线函数

## 挑战问题

- [ ] 指定起始端点位置的圆弧段自动生成（起止角度限制 + 八分对称组合）

## 提交

规定时间内验收；源码 + 可运行文件打包上传超星。

## 架构要求（影响后面所有实验）

- 本实验起就要设计好**底层数据存储类型与结构层次**、**基础功能封装与接口**——整个框架是一个"简易绘图引擎"，期末动画项目直接长在它上面
- 功能函数与前端界面**低耦合**：算法层不感知 UI
