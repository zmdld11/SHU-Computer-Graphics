# 实验四：二维曲线设计

> 前置：基于统一引擎框架；与实验三的交互（鼠标拾取/拖动）能力衔接。

## 必做内容

实现**二维 n 阶 Bezier 曲线**绘制。

## 验收要点

- [ ] 键盘或鼠标交互输入控制点
- [ ] 使用 **de Casteljau 算法**生成曲线（不能用 Bernstein 多项式展开直接求值替代）
- [ ] **n 阶**：控制点数量不固定（至少支持到 6~8 个控制点）
- [ ] 基于鼠标交互实现**曲线形状控制调整**（拖动控制点实时更新曲线）

## 挑战问题

- [ ] 二维 n 阶 **B 样条**曲线的绘制

## 提交

规定时间内验收；源码 + 可运行文件打包上传超星。
