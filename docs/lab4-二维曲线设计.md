# 实验四：二维曲线设计

> 前置：基于统一引擎框架；与实验三的交互（鼠标拾取/拖动）能力衔接。
> 实现：`src/curves/Bezier.{hpp,cpp}`（必做）+ `src/curves/BSpline.{hpp,cpp}`（挑战题）+ `src/ui/PaintController`（模式 8 交互），2026-10-15 完成。

## 必做内容

实现**二维 n 阶 Bezier 曲线**绘制。

## 验收要点

- [x] 键盘或鼠标交互输入控制点（模式 `8 曲线`：左键连点控制点，右键提交，≥2 点；任务栏同效）
- [x] 使用 **de Casteljau 算法**生成曲线（不能用 Bernstein 多项式展开直接求值替代）——`deCasteljauAt` 逐层线性插值"割角"，`sampleBezier` 均匀采样 128 段折线
- [x] **n 阶**：控制点数量不固定（至少支持到 6~8 个控制点）——de Casteljau 对任意 n+1 个控制点成立，无上限
- [x] 基于鼠标交互实现**曲线形状控制调整**（拖动控制点实时更新曲线）——曲线模式下已提交曲线显示灰虚线控制多边形 + 青色控制点手柄，按住拖拽即实时改形（改控制点参数→提交层重算），拖拽中的点橙色高亮

## 挑战问题

- [x] 二维 n 阶 **B 样条**曲线的绘制——`src/curves/BSpline.{hpp,cpp}`：Cox-de Boor 递推求基函数，
  **clamped 均匀节点矢量**（两端 p+1 重节点）保证曲线过首末控制点、便于与 Bezier 对比与对接拼接；
  实际阶数自动取 `min(degree, 控制点数-1)`，控制点不足时优雅退化为低阶（2 点=直线）。
  曲线模式按 `B` 键/任务栏按钮切换新曲线类型（标题栏显示；已提交曲线记住自身类型）。
  关键性质（测试自证）：4 控制点的 clamped 三次 B 样条逐点等于三次 Bezier（基函数退化为 Bernstein 基）。

## 与实验三的一致性

曲线是参数图形，完整接入变换模式（键 7）：可被左键选中（点到采样折线距离 ≤ 5px）、可被框选
（采样折线与矩形相交判定）、重心 = 控制点平均（与多边形同口径）、平移/缩放/旋转直接变换控制点
（**保留浮点精度**，Bezier 经仿射变换仍是 Bezier）、对接拼接（`J`）可吸附曲线轮廓最近点，
切向沿所在采样段方向。

## 实现记录

- **断言点选取的坑**：像素级断言最初取 B(0.5)，恰好同时落在曲线**与控制多边形**上（P1→P2 段
  中点 = 曲线中点），曲线模式下控制多边形虚线会盖掉曲线像素导致断言失败——不是 bug，是两个
  图元在该点重叠。断言点改取 B(0.25)（不在控制多边形上）。
- **接口调整说明**：占位接口 `sampleBezier(controlPoints, segments)` 保留不变；为复用命中/渲染，
  新增 `deCasteljauAt(controlPoints, t)` 单点求值（sampleBezier 的内层递推）。
- 采样段数取常量 128：折线在 800×600 下视觉光滑，且段数确定性使像素断言可写。
