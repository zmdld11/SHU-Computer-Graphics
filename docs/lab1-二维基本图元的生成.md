# 实验一：二维基本图元的生成

> 来源：《计算机图形学》实验要求。实验一~四必须在**同一个程序框架**中实现，人机交互驱动。
> 状态：**已完成**（#2 / PR #6，虚线修复 #13、#17，tag `lab1`）。四个任务**最后统一验收**（老师确认）。

## 必做内容

- [x] **直线段生成**：中点算法 或 Bresenham 算法（采用 Bresenham，任意斜率）
- [x] **圆弧生成**：中点算法（八分对称 + 角度过滤出弧段）
- [x] **线型、线宽属性**控制（实线/虚线/点线 × 宽 1/3/5，全部图元生效）

## 验收要点

- [x] 键盘或鼠标交互输入算法所需数据（端点、圆心半径等）：拖拽交互 + 键位切换
- [x] 直线绘制支持**任意斜率**（水平/垂直/|m|>1/m<1/负斜率都要对）：驱动轴切换实现，smoke 断言覆盖
- [x] 线型：至少实现实线 + 虚线（点线可选）：三种均已实现
- [x] 线宽：至少两种宽度：1/3/5 三档
- [x] **算法手写**，不调用图形库现成画线函数：只经 FrameBuffer::putPixel

## 挑战问题

- [x] 指定起始端点位置的圆弧段自动生成（圆弧模式：拖拽定圆心/半径/起点角，移动调终止角）

- 本实验起就要设计好**底层数据存储类型与结构层次**、**基础功能封装与接口**——整个框架是一个"简易绘图引擎"，期末动画项目直接长在它上面
