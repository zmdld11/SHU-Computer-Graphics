# 实验三：二维图形变换

> 前置：基于实验一、二的引擎框架；图形对象需可选中、可管理。
> 实现：`src/geom/Transform.{hpp,cpp}`（矩阵数学）+ `src/ui/PaintController`（模式 7 交互），2026-10-13 完成，tag `lab3`。

## 必做内容

平移、放缩、旋转三种几何变换。全项目图形为**参数化存储**（端点 / 圆心+半径 / 圆弧角度 / 顶点表），
变换 = 改参数后整体重绘，这也是老师验收时确认的关键点（"缩放要能拿到端点"）。

## 验收要点

- [x] 绘图区存在**多个图形**，鼠标可**选中一个或多个**后执行变换（左键单选，Shift+左键加选/移除，点空白取消；命中判定：线段距离 / 圆环 / 弧角范围 / 多边形内部，容差 5px）
  - **框选**（验收反馈补充，老师要求提供框选形式，#44）：空白处左键拖拽橡皮筋矩形（品红虚线预览），松开时与矩形相交的可选图形全部选中，`Shift`+框选与已有选中叠加；圆用解析相交（圆心到矩形最近点距离 ≤ 半径），弧按角度范围采样，线段/多边形边按 ~4px 步进采样
- [x] 变换默认参考点为**图形重心**（线=中点，圆/弧=圆心，多边形=顶点平均，多选=各重心平均；青色十字标当前参考点）
- [x] 支持以**任意点**为参考点执行三种变换（`G` 后左键点画布，rotateAbout / scaleAbout 即 T·R·T⁻¹ / T·S·T⁻¹）
- [x] 齐次坐标 / 矩阵实现（3×3 Mat3，列向量约定 `v'=M·v`；不是逐点 if-else 拼坐标）
- [x] **画板式选择编辑**（用户验收反馈，#51）：选中图形**橙色高亮重描** + **虚线最小外接矩形** + **控制柄**（替代旧的重心十字标记——曲线等图形重心不在本体上，一个点看不清）
  - 外接矩形：线=两端点 / 圆=圆心±r / 弧=角度采样 / 多边形=顶点 min-max / 曲线=采样折线 min-max；多选取并集
  - **单选线段 → 端点编辑模式**：只画两端点柄（7×7 橙色方柄黑描边），拖动直接改端点参数
  - 多选/其他图形 → 8 向柄：角柄=双向缩放、边柄=单轴缩放（锚点=对角/对边）；**选中含圆/弧时只给 4 角柄=等比缩放**（无椭圆参数化，与 +/- 缩放同一设计决策）
  - 柄拖拽**从拖拽开始的快照每帧重算**（scaleAbout 作用于快照），规避整数参数逐帧叠加的舍入漂移
  - `Del`/`Backspace`/任务栏按钮删除选中图形（从大到小删避免下标位移）

## 挑战问题

- [x] 在两个图形轮廓上指定**对接点**，通过几何变换将两图形在对接点处**拼接**（`J`：点击 A 轮廓→吸附最近点，点击 B 轮廓→对 B 施加 `M = T(A−B)·R(B,Δθ)`；Δθ 为两对接点**切向角差**、±90° 内取最短；切向=线段方向 / 半径转 90° / 多边形边方向）

## 实现记录

- **平移**：拖拽选中图形（整数增量，无舍入累积）或方向键微移 1px（可长按连发）
- **放缩**：`+` / `-` 等比 ×1.1 / ÷1.1，或拖外接矩形控制柄（画板式，见验收要点）。**设计决策**：圆只有"圆心+半径"参数，非等比缩放会变椭圆、超出参数表达能力，故只做等比（issue #35）
- **旋转**：`R` 逆时针 / `T` 顺时针 5°；圆弧变换时 startDeg/endDeg 同步加旋转角，与 drawArc 的屏幕顺时针角度约定一致
- **舍入说明**：图形参数为整数像素坐标，矩阵结果四舍五入回存；连续多次旋转/缩放理论上有 ±1px 累积（课程精度足够，报告可作已知取舍）
- **种子填充与裁剪线段不参与选中**：前者是像素操作记录、后者是演示辅助，均非参数图形
- 自测：56 项断言全绿（几何 6 + 交互 9 + 对接 2 + 既有回归）
- **顶部自绘任务栏随本实验一并交付**（老师要求以界面交互为主）：自绘按钮 + putPixel 文字，覆盖全部操作，键盘保留为快捷键（extension #39/PR#40，并入本 tag）；后升级系统字体中文按钮（#42）
