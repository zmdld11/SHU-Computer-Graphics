# SHU-Computer-Graphics —— 计算机图形学实验与课程项目

> 上海大学 2026-2027 秋季学期《计算机图形学》08306027

本仓库承载 **实验一~四（必做）+ 实验五（选做）** 的统一"简易绘图引擎"，以及在此基础上开发的**期末课程项目（二维动画程序）**。

## 技术栈

| 项 | 选择 | 说明 |
|---|---|---|
| 语言 | C++17 | |
| 构建 | CMake ≥ 3.20 | 一份 `CMakeLists.txt`，所有 IDE/命令行通用 |
| 图形库 | OpenGL 3.3 + GLFW + GLAD | GLFW 仅作"显示画布"，**所有光栅化算法手写**（Bresenham 等），符合实验考察点 |
| 依赖管理 | FetchContent(GLFW) + 自写 GL 加载器 | GLFW 首次构建联网自动拉取；GL 加载器是自写的 `src/core/GLLoader.*` |

## 构建与运行

```bash
# 方式一：命令行（首次会联网下载 GLFW）
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

# 方式二：CLion —— 直接用 Open 打开本目录（自带 CMake/Ninja）
#           运行配置选 farm-game = 直接进游戏；选 cg-engine = 编辑器/命令行模式
# 方式三：Visual Studio —— 文件→打开→CMake，选择本目录
```

```bash
./build/cg-engine            # 交互绘图（Windows 下为 build/cg-engine.exe）
./build/cg-engine --smoke    # 无窗口算法自测（212 项断言，退出码 0 = 通过）
./build/cg-engine --demo     # 无窗口导出演示图 demo.ppm（自查/报告插图）
./build/cg-engine --demo-ui  # 无窗口导出 UI 演示图（任务栏+图形+常驻裁剪+选中）
./build/cg-engine --stress-ui # 无窗口交互压力测试（越界画图/拖拽出画布/极小裁剪窗，崩溃回归）
./build/cg-engine --bench-ui # 无窗口性能基准（裁剪开/关、凸多边形窗、拖拽帧耗时）

./build/farm-game                # 直接进入胖龙农场（CLion 选 farm-game 目标即可）
./build/cg-engine --game         # 同一游戏的命令行入口（点选移动/种植/钓鱼/昼夜/小屋）
./build/cg-engine --game-capture # 无窗口导出背景、分层帧、昼夜四时刻、特效与室内预览
./build/cg-engine --game-smoke   # 无窗口农场自测（玩法/钓鱼/昼夜/场景切换 73 项）
```

> CLion 打开的是 **`cg-labs` 目录**（`CMakeLists.txt` 所在层）。加载后左上角运行配置选
> `farm-game`，点运行直接进游戏；`cg-engine` 则用于编辑器和其他命令行模式。

> Windows 工具链：MSVC (VS2022) 或 MinGW 皆可。

### 操作说明（实验一 / 实验二 / 实验三 / 实验四）

| 输入 | 功能 |
|---|---|
| `1` / `2` / `3` | 直线 / 圆 / 圆弧 模式（圆弧：拖拽定圆心半径起点角 → 移动调终止角 → 左键确认） |
| `4` | 多边形模式：左键连点顶点（橡皮筋预览），**右键闭合**（≥3 点）；`F` 切换 填充 / 仅轮廓（连点中＝改本次闭合样式；其他时候＝切换**最后一个已闭合多边形**，可来回切） |
| `5` | 种子填充模式：左键点击封闭区域内一点（`X` 循环填充色）；点在圆/多边形内部时种子会**绑定该图形**，之后缩放/平移/旋转/对接时填充跟随，删除图形时填充一起删除；点在其他连通区域则是自由种子填充 |
| `6` | 裁剪模式：左键拖拽画线（灰虚线=原线段，绿=裁剪结果，演示 C-S/中点分割/Cyrus-Beck 算法）；`K`+拖拽设矩形窗口；`P`+左键连点+右键闭合设凸多边形窗口；`M` 切换算法。**定义窗口后进入常驻裁剪**：窗口以青色虚线常驻屏幕，任意模式下画直线/圆/圆弧/多边形/曲线都只显示窗口内部分，`V` 随时开关 |
| `7` | **变换模式**：左键点图形选中（`Shift`+左键 加选/移除），**空白处左键拖拽=框选**（橡皮筋矩形，松开时相交图形全部选中，`Shift`+框选叠加）；**命中更宽松**：多边形点内部或边附近、圆点内部或圆环都能选中。**多选形成外接矩形后，从矩形内空白处拖动 = 整体拖拽**（类似 PPT 组合体；点矩形外才开始新框选）；拖拽或方向键平移；**选中图形橙色加粗轮廓 + 虚线最小外接矩形 + 控制柄**（保留原填充色）：拖角柄缩放（圆/弧仅 4 角柄=等比；按住 `Shift` 任意图形都等比、按住 `Ctrl` 以选区中心为锚对称缩放）、拖边柄单轴缩放、**单选线段时可拖两端点柄直接改形**；`Del` 删除选中；`+`/`-` 等比缩放 ×1.1；`R`/`T` 旋转 ∓5°；**右键拖拽 = 绕参考点任意角度旋转**（拖动时显示参考点→光标引导虚线与角度读数，按住 `Shift` 吸附 15°）；`G` 切换参考点（默认=选中图形**重心**，指定=按左键点画布任一点，青色十字标记）；`J` 对接拼接（挑战题：依次点两图形轮廓，第二个图形被变换到与第一个在对接点相接） |
| `8` | **曲线模式**（实验四）：左键连点控制点（以光标作临时末控制点实时预览曲线），**右键提交**（≥2 点）——de Casteljau 生成 n 阶 Bezier；`B` **三态循环**曲线类型：Bezier → **B 样条·固支**（clamped 节点，过首末控制点）→ **B 样条·均匀**（均匀节点，**不过首末控制点**，4 点就能看出与 Bezier 的差别）→ Bezier，并同时切换最近一条已提交曲线方便对比；**点住已提交曲线的控制点拖拽**即实时调整形状（控制多边形灰虚线 + 青色手柄，拖拽点橙色高亮） |
| `S` / `W` / `X` | 线型（实/虚/点） / 线宽（1/3/5） / 填充色 |
| `Shift`（按住） | **约束类修饰键**：画直线时方向吸附 45° 整数倍（0°/45°/90°/…，长度取投影分量）；变换模式拖动平移同样沿水平/垂直/45°；拖控制柄时等比缩放；拖线段端点柄时方向吸附 45°；右键拖拽旋转时角度吸附 15° 整数倍 |
| `Ctrl`（按住） | **定步长修饰键**：画圆/圆弧时半径按 20px 步进（20/40/60…）；拖线段端点时长度按 20px 步进（`kStepPx`）；变换拖控制柄时以选区中心为锚；平移时偏移吸附 10px 网格 |
| `Ctrl+Z` | **撤销**：图形增删、变换、清屏、裁剪窗修改都可回退（快照栈，最多 64 步；任务栏也有「Ctrl+Z 撤销」按钮） |
| `V` | 常驻裁剪开关：窗口外内容隐藏 ⇄ 恢复（定义过裁剪窗口后有效；`E` 清屏只清图形、不动窗口） |
| `E` / 右键 | 清屏 / 取消当前操作（变换模式下有选中时，右键按下并拖动是旋转，见 `7`） |
| 拖窗口边缘 | 调整画板大小（内容清空） |
| `ESC` | 退出 |

### 任务栏（推荐入口）

窗口顶部有**自绘任务栏**（两行按钮，高度随字体度量自适应，宋体 16px 下约 55px），鼠标点击即可完成**全部操作**，无需记快捷键：

- 第一行：`1 直线` ~ `8 曲线` 八个模式按钮（当前模式高亮）+ `E 清屏`
- 第二行：`S 线型`/`W 线宽`/`X 颜色` 属性循环 + 随模式变化的上下文按钮——多边形：`F 填充:开/关`、`右键闭合`；裁剪：`K 矩形窗`、`P 多边形窗`、`M 算法`；变换：`+`/`-`/`R 逆旋`/`T 顺旋`/`G 参考点`/`J 对接` 与 `←→↑↓` 微移；曲线：`B 类型:Bezier/固支/均匀`、`右键结束`；定义过裁剪窗口后所有模式追加 `V 裁剪:开/关`

任务栏文字在 Windows 上由 **GDI 把系统字体（宋体 16px）栅格化成点阵**（`src/ui/Text.{hpp,cpp}`，字形按字符懒缓存），非 Windows 回退自写 5×7 点阵（`src/ui/Font5x7.hpp`）；点阵仍逐像素写入 FrameBuffer，**没有任何界面框架**。键盘按键全部保留为快捷键（与按钮共用同一操作入口 `handleAction`）。当前模式与属性仍实时显示在窗口标题栏。

## 期末项目：胖龙农场（M1）

基于同一套引擎的 2D 俯视农场小游戏，设计稿见 [`docs/期末项目-奶龙农场.md`](docs/期末项目-奶龙农场.md)。

| 输入 | 功能 |
|---|---|
| 左键点地面 | 按 32px 格移动，先横后竖；被池塘/边界挡住时 BFS 绕行，停在格心 |
| 左键点农田 | 走到田块中心（M2 到达后自动播种/浇水/收获） |
| 左键点水面/栈道 | 走到栈道尽头（M3 到达后自动抛竿；咬钩窗口再点水面） |
| 右键 / `1` `2` `3` / `R` | 取消移动 / 选种子 / 重开 |

地图 1536×1152，窗口 800×600 跟随角色滚动，到世界边缘后镜头停住、角色偏移。静态背景以 2× 超采样烘焙一次，之后每帧只做相机窗口拷贝；胖龙、农田、池塘、土路全部由手写光栅算法和矢量图元绘制，无外部素材。

CLion 里选 **`farm-game`** 目标直接运行（无需参数）；命令行也可用 `./build/farm-game` 或 `./build/cg-engine --game`。

## 目录结构

```
SHU-Computer-Graphics/
├── AGENTS.md          # 组员 AI 助手工作指引（AI 编程工具自动读取）
├── CONTRIBUTING.md    # 协作规范：issue 驱动工作流
├── docs/              # 实验要求摘要、架构设计（类图与依赖）、OpenGL 显示原理
├── src/
│   ├── core/          # FrameBuffer（putPixel 唯一画点入口）、GLLoader、Canvas 上屏
│   ├── raster/        # 图元生成（实验一）、填充与裁剪（实验二）
│   ├── geom/          # 几何变换 Mat3：平移/放缩/旋转/绕任意参考点（实验三）
│   ├── curves/        # Bezier（de Casteljau）+ B 样条（Cox-de Boor）曲线采样（实验四）
│   ├── game/          # 期末项目：FarmLayout/FarmWorld/FarmRender/FarmGame
│   ├── tests/         # 算法自测（--smoke）、演示图（--demo）、农场自测（--game-smoke）
│   ├── ui/            # GLFW 窗口 + PaintController 交互状态机 + 自绘任务栏（Text 系统字体栅格化，Font5x7 回退）
│   ├── main.cpp       # cg-engine 入口：编辑器 + 各命令行模式
│   └── game_main.cpp  # farm-game 入口：直接进游戏
└── CMakeLists.txt     # 仓库不含任何第三方源码
```

**关于 OpenGL 加载器**：Windows 上 OpenGL 1.1 之后的函数地址须运行时向显卡驱动查询。这项工作由**自写**的 `src/core/GLLoader.{hpp,cpp}`（约 180 行）完成——只加载本工程实际用到的 33 个函数（`Canvas` 是唯一使用者），仓库因此不含任何第三方源码。历史版本曾用生成器库 glad（2 万余行），2026-09-20 起替换（#29）。

**架构红线**：算法层（raster/geom/curves）不依赖 UI 层，绘图只经 `FrameBuffer::putPixel`；期末游戏项目只调底层接口，`PaintController` 一行不改。

**课程要求原文**（老师实验注意事项，做任何改动前对照一遍）：

> 在进行实验一到四的过程中，充分考虑整个系统底层数据存储类型和结构层次设计，基础功能的封装和接口设计，使其成为一个简易绘图引擎。后续能够支持实现上层具体动画效果，即最终的课程设计需要依赖前期基础架构。考虑具体功能函数与前端界面的低耦合。

**依赖白名单**（低耦合的落地红线：全项目只允许以下外部依赖，**禁引入 Qt / MFC / ImGui / WebView 等任何界面或前端框架**，UI 只做事件转发）：

| 依赖 | 用途 | 使用边界 |
|---|---|---|
| GLFW | 窗口与鼠标键盘事件 | 仅 `src/ui/Window.cpp` 使用；`src/game/FarmGame.cpp` 只读按键常量 |
| OpenGL 3.3（系统自带 opengl32） | 把 framebuffer 贴上屏 | 仅 `src/core/Canvas.cpp` 使用 |
| CMake | 构建 | — |

> 仓库**不包含任何第三方源码**：连 OpenGL 函数加载器都是自写的（`src/core/GLLoader.{hpp,cpp}`，约 180 行）——Windows 上 OpenGL 1.1 之后的函数须运行时向驱动查询地址，这份小文件只做这件事，原理见 `docs/OpenGL与界面交互.md`。
